# Optimizaci-n-de-planes-de-radioterapia-de-intensidad-modulada-mediante-metaheur-sticas
 La planificación manual de radioterapia de intensidad modulada (IMRT) para cáncer de cabeza y cuello consume entre dos y cinco horas por paciente y depende de la experiencia del oncólogo. Este trabajo evalúa tres metaheurísticas para optimizar las intensidades de nueve haces de radiación.
